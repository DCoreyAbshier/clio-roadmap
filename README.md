# Clio Roadmap

Clio is an AI-assisted role-playing engine focused on coherent long-running worlds, characters, and scenes.

This repository is the public, high-level roadmap for Clio. It intentionally excludes private source code, detailed architecture, internal acceptance criteria, security information, and deployment details.

## Current direction

The roadmap is being initialized from Clio's canonical private planning issue. Public roadmap cards and status links will appear here shortly.

## Status meanings

- **Active** — currently being implemented.
- **Next** — the immediate follow-up after active work.
- **Planned** — ordered work that follows the active and next items.
- **Deferred** — intentionally held until its entry conditions are met.
- **Opportunistic** — maintenance performed when an appropriate opening appears.

## Tracking

Progress is tracked through this repository's public [issues](https://github.com/DCoreyAbshier/clio-roadmap/issues). Closing a public roadmap issue means the corresponding high-level outcome has been delivered.
